# Danh sách học viên

Sửa file `danhsachhocvien.txt` trong thư mục này: mỗi dòng một tên.
Tên sẽ hiện trong ô "Tên học viên" ở trang luyện tập.

Khi học viên bấm "Nộp và in kết quả", trang mở phiếu kết quả để in,
hoặc chọn "Lưu thành PDF" (Save as PDF) trong hộp thoại in để xuất file PDF.
Site không lưu kết quả lên máy chủ hay Google Sheet.
